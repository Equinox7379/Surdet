# 文档归档规则

本目录只承载已经明确批准归档的材料。仓库中的文档按以下四类管理：

1. `docs/` 下的维护中技术文档：描述当前实现、接口、能力和操作方式，必须随代码事实更新。
2. `docs/superpowers/` 下的当前计划与规格：描述正在执行或待执行的实现任务，完成后保留为可追溯的设计记录。
3. 不可变的验收证据与历史交接件：可在另行取得项目负责人批准后移动到本归档目录；移动时保留原文件内容和来源说明。
4. 内部 AI/会话记忆：根目录的 `USER.md`、`SESSION-HANDOFF.md` 属于工作上下文，绝不自动提交，也不因仓库整理被删除或移动。

本轮不批量移动既有的 113 个已发布历史文件。任何历史材料迁移都必须单独列出范围、得到负责人批准，并在迁移前后执行链接和 Git 历史核对。
