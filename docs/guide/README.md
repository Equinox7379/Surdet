# Surdet 作者指南

这份指南写给用 Surdet Editor 做视觉小说的作者，不需要读源码，也不需要会写程序。照着做，你可以从空白项目开始，写剧本、加行内样式、导入素材、试玩、检查分支，最后导出一个能在 Windows 上运行的游戏文件夹。

第一次使用，建议先跟着[完整教程](tutorial.md)做一遍。教程用空白模板做一个两条分支、一个结局的短篇《雨夜车站》，大约需要一小时。之后按需要查阅下面各章。

## 截图与版本说明

- 截图取自主线 `6ab6dff` 构建的桌面版 Editor，在 Linux 云端环境中运行。图里的文件夹路径是 Linux 路径，在 Windows 上会显示为 `C:\…` 这样的路径。
- Windows 部分由技术负责人用当前日常打包的 Editor 核对过：从启动页创建中文名的空白项目并保存角色；用教程的剧本和占位图导出「雨夜车站.exe」，并运行到开场。真人操作 Windows 系统文件夹选择框还没有核对。本指南中凡是 Linux 环境没有实际执行的步骤，都会单独注明。
- 标有「修复在 #41 / #42，还没合入」的地方，说的是当前日常 Editor 仍有的问题，修复合入后会更新。
- 标有「待合入」的小节，介绍的是已经验收、但还没合入主线的功能（PR #36、#38、#39）。这些截图来自本地合并后的构建。当前日常使用的 Editor 还没有这些功能，合入后才会出现。
