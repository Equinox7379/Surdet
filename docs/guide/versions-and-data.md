# 版本与数据支持

> **草稿，待技术核对。** 本页由 Claude 按 `6ab6dff` 的代码和现有文档起草，列的是已经能在代码里找到的事实。技术负责人核对之前，不作为对作者的承诺；哪些旧版本受支持，以核对后的版本为准。

作品里有三类数据会随引擎升级而变化：剧本、项目文件和玩家存档。

## 剧本（`.gal`）

- 写法以 [DSL 规范](../dsl-spec.md) 为准。规范标题写的是「v0.1」，`.gal` 文件里不记录版本号。
- 引擎更新后，旧剧本照常读取，Editor 不会自动改写你的剧本。有问题的写法会出现在问题列表里。
- 已知的写法变化：注音只认 `<ruby=读音>字</ruby>`，不再兼容旧的 `世界《せかい》`。旧写法**不会报错**，而是按字面显示全部字符（书名号原样显示）。需要自己用查找搜「《」，逐处改成新写法。

## 项目文件

- 导出 Windows 游戏时，「Windows 版本」的默认值取自 `package.json` 里的 `version`。`game.config.json` 里也有一个 `version`，导出不读它。两者都是**作品**的版本号，和引擎版本无关。
- `package.json` 里的 `name` 是作品身份，决定玩家存档的位置，不要修改。
- 配置里各部分（例如译稿目录 `textCatalog`、作品界面 `ui`）有各自的结构版本号，由 Editor 读写，作者不需要手动改。

## 玩家存档

- 当前存档结构版本是 **3**（`packages/core/src/save/save-manager.ts` 中的 `SAVE_SCHEMA_VERSION`）。
- 读取版本 1、2 的旧存档时，会逐级升级到版本 3 再读（`packages/core/src/save/migrate.ts`）：版本 1→2 补上空的调用栈，版本 2→3 只升版本号。没有版本号的存档按版本 1 处理。
- 版本号**高于**当前引擎支持的存档会被拒绝，提示「存档 schema 版本 X 高于引擎支持的 3」；缺少升级路径的存档也会被拒绝，不会强行读取。
- 用到项目插件的存档，读取前要先启用对应插件，否则提示 `PLUGIN_REQUIRED`。
- 文字记录随存档保存。没有文字记录字段的旧存档，读档后从空记录开始。
- 已知限制：修复前生成的、正处于某些时间轴淡入或染色效果中途的旧存档，读档时会被明确拒绝，不会猜测效果的起点。没有处在这些效果中途的旧存档不受影响。见[当前限制](../known-limitations.md#旧版演出中途存档)。

## 剧本改动和旧存档

作者发布新版本后，玩家用旧存档继续玩时会怎样（例如存档所在的那句台词被改掉或删掉），**本页暂不作说明**，待技术负责人按实际实现补充。在此之前，建议发布更新前用旧存档实际试一遍。

## 设置

玩家设置（文字大小、减少动态效果等）属于设备，不写进存档，也不随作品版本变化。
