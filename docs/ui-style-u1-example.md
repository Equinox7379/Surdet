## 示例内容

[`ui-style-u1-example.ui.json`](ui-style-u1-example.ui.json) 是一份可直接放进 `game.config.json` 的 `ui` 文档，覆盖一部作品最常看到的四页；没写的页面继续使用默认界面。配色取自《雾港来信》示例的雾白 / 海蓝，不使用任何素材，所以在任何项目里都能打开。

| 页面 | 展示的 U1 字段 | 试看重点 |
| --- | --- | --- |
| 标题 | 卡片：底色 + 背景不透明度 0.92 + 1px 边框 + 圆角 + 内边距 + 框体阴影；标题：字重 700、字距、文字阴影；主按钮：两色渐变 + 边框 + 阴影；次按钮：`backgroundImage: null`（停用主题按钮皮肤） | 卡片内容按内边距排布；Tab 依次聚焦四个按钮，Enter 触发；装饰阴影不扩大点击区 |
| 对白 | 对白框：渐变 + 背景不透明度 + 边框 + 圆角 + 内边距 + 阴影；正文：行高 1.7、字距 0.5 | 长句换行；阅读字号 140% 时超出部分可用滚轮、方向键 / PageUp / PageDown 回读，每行步长等于实际行高 |
| 选项 | 选项按钮模板：底色 + 背景不透明度 + 边框（半透明）+ 圆角 + 阴影 + 字距，`backgroundImage: null` | 不可选项整体变淡（装饰层与文字一起 0.45）；Tab / Enter 选择；140% 时文字不被裁掉 |
| 文字记录 | 面板：底色 + 边框 + 圆角 + 内边距 + 阴影；列表：行高 1.6、字距、边框 + 圆角；返回按钮：渐变 | 注音、着重号、粗体照常显示；列表滚动 |

标题页的说明行固定写着「U1 样式示例 · 非最终美术 · 未用于默认外观」，截图或试玩时不会被误认为定稿。

## 怎么试

1. 在测试项目的 `game.config.json` 里加入 `"ui": { …示例 JSON 的全部内容… }`；已有 `ui` 时只替换示例里的四个页面。
2. 打开 Editor 的「界面设计」，选页面和组件。属性栏下方按「文字 / 背景 / 框体与皮肤」分组，只列出当前组件真正会用到的属性；每项显示「继承：…」「已设置」或「已明确清空」，可「恢复继承」，也可按合同明确清空（如「透明背景」「无边框」「直角」「无阴影」「不用图片」）。
3. 点「试玩草稿」在真实 Player 中查看；保存后重开、撤销 / 重做走原有界面草稿路径。

## 九宫格皮肤变体（需要作者素材）

示例本身不带图片。要试九宫格：

1. 准备一张四角有装饰的 PNG，例如 96×96、四角各 24px，放进背景素材（如 `assets/bg/u1-frame.png`，素材键 `u1-frame`）。
2. 选中按钮或面板 →「背景图片」选 `u1-frame` →「框体与皮肤」勾选「按九宫格拉伸」，上 / 右 / 下 / 左切边各填 24（原图像素），需要镂空时取消「绘制中心区域」。

对应数据：

```json
"style": {
  "backgroundImage": { "asset": "u1-frame", "fit": "stretch", "slice": { "top": 24, "right": 24, "bottom": 24, "left": 24, "fillCenter": true } },
  "padding": { "top": 12, "right": 20, "bottom": 12, "left": 20 }
}
```

四角按原尺寸绘制、边和中心拉伸；组件比两侧切边之和还小时，四角按比例缩小（几何由 Core `projectUiNineSlice` 按图片真实尺寸计算，Player 与 Editor 画布共用）。切边超过图片尺寸会被现有保存检查拒绝。测试用皮肤只用于验证技术效果，不代表最终画风。

## 已知限制（本示例不处理）

- 内容列表（选项、存读档、记录）的行底色、分隔线与行内边距仍是现有默认外观；合同没有行样式字段，本轮不新增。
- 字距是设计稿像素，不随阅读字号倍率放大；行高是倍率，会随字号变化。
- 示例只覆盖四页。设置、鉴赏、存读档、系统菜单等页面的成套美术需等生成美术到位后再做，本示例不能当作成品界面设计。
