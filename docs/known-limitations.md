# 当前限制

这份清单只记录仍影响产品声明或创作决策的当前边界。历史修复过程请从 Git 历史读取，不在这里复制施工报告。

## 战斗阵型

当前战斗使用一维位置模型，已经支持移动、射程、冷却、敌方行动与基础交互，但尚未提供开战前阵型编辑、多格占位和阻挡规则。能力矩阵中的 `battle-formation` 因此保持 `planned`，不能写成已实现。

## 随机数确定性

部分模拟和证据接口已经接受并记录 `seed`，但 DSL `@random` 当前仍使用 `Math.random()`。在独立可靠性任务修复并验证这条链之前，不宣称 Surdet 具备全链路 seeded determinism。

## 性能证据范围

`docs/baselines/` 保存的是指定提交、指定设备和指定资格化协议下的冻结证据。它们用于回归比较，不代表所有设备、游戏内容和发行包都满足同一性能结论。

## 音频与人工体验

音频生产不在当前主线。自动化可以验证文件、路由、生命周期和基础响度，但不能替代项目所有者对音乐、音效、视觉和交互手感的实机判断。

## 发布边界

测试、FORMAL、外部 Agent 和人工验收分别提供不同证据。任何一个门通过都不会自动授权 push、部署、打包或发行。
