# 当前限制

这份清单只记录仍影响产品声明或创作决策的当前边界。历史修复过程请从 Git 历史读取，不在这里复制施工报告。

## 战斗阵型

当前战斗使用一维位置模型，已经支持移动、射程、冷却、敌方行动与基础交互，但尚未提供开战前阵型编辑、多格占位和阻挡规则。能力矩阵中的 `battle-formation` 因此保持 `planned`，不能写成已实现。

## 随机数确定性

部分模拟和证据接口已经接受并记录 `seed`；本 Wave 已为 DSL `@random` 建立可快照的 `mulberry32-v1` seeded source，并验证了 save/load 后的序列连续性。无 seed 的普通玩家解释器仍保留 `Math.random()` fallback，其他未纳入本 Wave evidence contract 的随机路径也未被覆盖，因此仍不宣称 Surdet 具备全链路 seeded determinism。

## 性能证据范围

`docs/baselines/` 保存的是指定提交、指定设备和指定资格化协议下的冻结证据。它们用于回归比较，不代表所有设备、游戏内容和发行包都满足同一性能结论。

## 旧版演出中途存档

修复后的时间轴 fade/tint 会保存原始插值起点及动作归属。修复前生成的存档若正处于这些效果中途且缺少原起点，无法可靠还原连续轨迹，读档会在修改当前游戏状态前明确拒绝；不猜测起点、不改写旧存档。没有活动 fade/tint 中途状态的旧存档不因这项修复被统一拒绝。此前旧式立绘转姿态时生成的缺字段过渡快照，也不会通过放松校验强行接纳。

## 作品多语言

P6b 消费作者显式确认的正文、选项、人物显示名、自定义 UI 字面文字/分页标题和名词表规范词。源剧本版本变化必须重新核对对应；缺译、过期或失配时回退原文。不自动翻译、不模糊配句，也不翻译系统按钮、路径/变量/标签、任意数据绑定值或词条在正文中的出现。读档使用当前设备语言；历史记录和 NVL 已读旧段的正文不重新翻译。源码热更新后需重读项目并重新确认来源，不能用旧映射猜测新正文。

P6c 只按对白文本键和语言关联已有录音，选项/界面字段不自动朗读。缺录音或录音台词过期时允许无声阅读，不借用其他语言。改词后需明确重新确认配音；素材元数据检查不验证录音语义、实际可解码性或听感。读档从当前句开头播放，不保存采样级声音进度；历史回放保留当时语音键。无目录配音的旧场景继续使用显式 `@voice`，不做自动配句或音频生产。

## 音频与人工体验

音频生产不在当前主线。自动化可以验证文件、路由、生命周期和基础响度，但不能替代项目所有者对音乐、音效、视觉和交互手感的实机判断。

## 发布边界

测试、FORMAL、外部 Agent 和人工验收分别提供不同证据。任何一个门通过都不会自动授权 push、部署、打包或发行。
