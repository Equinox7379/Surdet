# U3 技术主题示例（可复用，非最终美术）

> 状态：**技术示例，用来验证“导出 → 导入预览 → 确认应用”整条路径并给作者一套能直接复用的完整主题；不是 Owner 认可的最终美术，未应用到默认外观、新项目模板或两部作品。**
> 字段、单位和应用语义以[作品界面样式合同](ui-style-contract.md)、[界面交互合同](ui-interaction-contract.md)、[共享导入合同](ui-sharing-import-contract.md)及实际代码为准，本文不另立规格。

## 文件

[`ui-theme-u3-technical/u3-technical.surdet-ui-theme.json`](ui-theme-u3-technical/u3-technical.surdet-ui-theme.json) 是用 Editor「导出作品主题」生成的原有 `surdet-ui` / `version: 1` 完整主题共享文件，没有新格式、能力号或额外清单。它包含：

- `theme`：深海军蓝底 + 青色强调的 13 种颜色、5 项不透明度、字号与字距、间距（xs 4 / sm 8 / md 16 / lg 24 / xl 40，设计稿像素）、圆角，以及主题按钮皮肤 `u3tech_skin`、对白皮肤 `u3tech_dialog`；
- `player.titleBackground`：标题背景 `u3tech_title_bg`（不设标题 Logo）；
- `ui`：下面八页完整页面；
- 6 张 PNG（内嵌在共享文件里）：标题背景、面板九宫格、按钮常态/悬停九宫格、对白框九宫格、主题按钮皮肤。图片由 Surdet 程序化绘制，随仓库同一许可证，不含第三方素材。

不含字体、变量、剧情、存档或任何项目私有字段。

| 对白 | 九宫格对白框、说话人、正文 | 220ms 上移淡入 |

| 设置 | 分页签：文本速度、自动停留、文字大小、快进策略、朗读、五路音量、减少动态效果，数值实时显示；另有“全部”列表 | 滑块/开关/页签/返回按钮五态 |

所有页面进退场都受「减少动态效果」（系统设置或游戏设置）控制，开启后直接到终态。

标题页「鉴赏」按钮故意不写背景图，继承主题按钮皮肤 `u3tech_skin`（默认 HUD、快捷栏等未自定义页面也用它）；把标题按钮组当片段导入别的作品时，这个按钮会改用那部作品自己的主题按钮外观，其余按钮带着自己的九宫格图片。

## 怎么用

1. 打开自己的项目 → 配置 →「作品界面」→「导入主题或片段」，选择上面的共享文件。
2. 对话框只读预览：受影响页面（新增/替换/不变）、保留的本作品内容（剧情、变量、玩家其他设置、插件声明、私有字段）、主题与标题图片、字体变化、缺失或冲突的图片。可切换各页看真实 Player 画面、悬停/焦点、空状态、重播进场或按减少动态查看，也可「在 Player 中试玩」（进度和设置不保存）。
3. 第一次导入时 6 张图片都缺：点「加入素材导入」→ 在素材导入工作台保持文件名完成导入 → 回到作品界面点「继续导入」重新预览，图片齐全后「应用到草稿」。
4. 应用只改草稿、一次撤销点；用「保存全部」（Ctrl+S）把主题和界面一起写回。主题和界面都有未保存修改时，单独「保存界面」/「保存主题配置」会被拒绝，避免只写入一半。

导出自己的主题：作品界面 →「导出作品主题」；导出片段：选中组件 →「导出所选片段」。片段只带页面结构和用到的图片，继承目标作品的主题与字体。

## 已知限制

- 本主题不带字体。按现有应用语义，完整主题会把目标作品的字体设置换成共享文件里的字体设置（这里为空，即回到默认字体），对话框会写明“本包不带字体，应用后本作品改用 Player 默认字体”，确认前可取消；需要保留字体时，导入后重新选择，或导出时在源项目里一起设置字体。
- 系统菜单没有“回到标题”：现有界面动作没有此项，本轮不新增；默认 HUD、快捷栏等未自定义页面继续使用默认外观。
- 标题页「继续」只按现有启用条件显示，没有存档时不会自动变灰。
- 设置里的开关仍是原生复选框（只改强调色），内容列表的行底色、分隔线与行内边距仍是现有默认外观；合同没有对应样式字段，本轮不新增。
- 所有尺寸按 1280×720 设计稿；未在 Windows/Electron、原生输入法和导出包中验收。
