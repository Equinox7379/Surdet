# 《零点之后》一小时都市悬疑 ADV 设计

## Summary

《零点之后》是一部使用 Surdet 现有编辑器与 DSL 制作的原创都市悬疑 ADV。单周目目标时长为 55～70 分钟，包含一条共通篇和三条后半分线；三结局用于重玩，完整体验三线的实际游玩时长约为 2.5～3 小时。

视觉基准为现代 ADV：钢蓝雨夜为主色，便利店、路灯和记忆片段偶尔使用低饱和钠灯暖色；对白采用无框透明渐隐 HUD；人物使用底部锚定的近景胸像。标题页使用冷静字标方向，不使用 RPG Maker 式大面板或装饰性卡片。

## Story And Route Structure

主角在 `00:17` 接到失踪三天的旧识许知遥来电。每次通话约持续三分钟，许知遥会给出一个现实地点和一句互相矛盾的提示。玩家通过验证地点、记录声音、决定是否相信来电，逐步确认有人在模仿她的声音。

### Shared Chapters

| Segment | Scene | Target | Purpose |
| --- | --- | ---: | --- |
| Common 1 | `00:17` 主角公寓 | 8 min | 第一通电话；建立“不要开灯”、失踪三天和异常来电。 |
| Common 2 | 雨夜便利店 | 9 min | 电话背景音在现实地点出现；监控与许知遥的说法发生冲突。 |
| Common 3 | 旧公寓 | 9 min | 找到录音，确认有人模仿她的声音；录音含有只有她知道的私密内容。 |
| Common 4 | 地下通道 | 9 min | 发现第二部手机和失踪时间线；玩家进行明确的路线选择。 |

共通篇目标时长约 35 分钟。每个场景结束自动存档，地下通道分线选择前额外自动存档。

### Route Chapters

| Route | Scenes | Ending | Target |
| --- | --- | --- | ---: |
| 证词线 | 派出所深夜、天台终电 | 公开证据，真相成立，但电话仍在公开后打来。 | 20–25 min |
| 赴约线 | 夜班末班车、天台终电 | 按电话追踪许知遥，发现电话来自主角自己的手机。 | 20–25 min |
| 静音线 | 断电公寓、清晨街道 | 切断联系并活下来，但城市里仍继续出现她的声音。 | 20–25 min |

地下通道的行动选择明确映射到路线，不使用隐藏随机分线：

- 交给警方：进入 `证词线`。
- 继续按电话找她：进入 `赴约线`。
- 关机离开：进入 `静音线`。

三条路线共享主角、许知遥、核心地点和前半证据，后半各自拥有独立冲突与收束。单周目目标为 55～70 分钟；全部路线的重玩内容不压缩成同一段结尾。

## Variables And Narrative Rules

保留并使用现有变量：

- `trust`：主角对来电内容和许知遥身份的信任程度。
- `evidence`：玩家实际验证、保存或公开的证据数量。
- `panic`：主角在异常事件中的失控程度。
- `route`：地下通道选择后写入的路线标识，取值为 `testimony`、`meeting`、`silence`。

`trust`、`evidence`、`panic` 不会覆盖玩家的路线选择，只影响对应路线中可见的补充线索、录音内容和结局最后一段文本。变量阈值必须在脚本开头初始化，并且所有条件分支都提供可运行的 `@else` 回退。

推荐的叙事效果：`evidence >= 3` 时证词线显示完整证据链；`trust >= 3` 时赴约线能识别许知遥说话中的真实求救句；`panic >= 3` 时静音线保留更多不可靠听觉描述。阈值不足时仍进入对应结局，只显示信息不完整的变体，避免玩家因遗漏一次调查而无法通关。

选择肢使用短句和动作动词，不使用厚重按钮文案。调查选择同时更新变量并记录可读的文本反馈；关键路线选择前保留一次 `@autosave`。

## Assets And Audio

所有图像为原创位图，背景目标分辨率 `1920×1080`，立绘为透明 PNG，保持同一角色设计、服装和光源方向。素材不足时沿用引擎现有稳定占位回退，不猜测角色对应关系。

### Backgrounds

准备 11 张主背景：

- 共通：公寓亮灯、公寓断电、便利店外景、便利店内景、旧公寓走廊、旧公寓房间、地下通道。
- 分线：派出所档案室、末班车车厢、雨夜天台、清晨街道。

通过裁切、暗化、雨效、局部灯光和立绘移动产生演出变化，不为同一地点制作低价值重复背景。

### Character Art

许知遥使用普通通勤服装，制作 8 个底部锚定胸像状态：平静、迟疑、勉强微笑、湿冷、警觉、惊慌、沉默失焦、信号失真。失真状态使用透明度、冷色偏移和轻微错位表达，不做夸张恐怖变形。当前渲染接口每个角色只绑定一个静态对白头像，因此提供一张默认头像；情绪变化全部由主立绘呈现，不为切换头像新增引擎接口。

命名遵循当前素材管线：

```text
bg/apartment_night
bg/convenience_exterior
portrait/zhirao_commute_calm
portrait/zhirao_commute_wet
avatar/zhirao_calm
```

### Audio

提供 6 条无配音循环 BGM：标题、雨夜、调查、旧公寓、地下通道、终局；提供约 12 个 SE：来电、挂断、雨、脚步、门锁、便利店门铃、录音、地铁、灯管、电流、警笛、风声。BGM 在场景切换时淡入淡出；来电、录音和电流使用金色通话提示与轻微界面失焦同步，但不能遮挡对白。

## Editor Integration

新游戏作为独立工程放入 `examples/zero-after-midnight`，复用当前 starter 的 Vite、运行时、编辑器和素材 postMessage 管线，不修改 `examples/starter` 的剧情或素材。剧本按场景文件拆分，使用现有 DSL 指令：

`@bg`、`@bgm`、`@se`、`@show`、`@mov`、`@hide`、`@choice`、`@set`、`@mod`、`@if`、`@jump`、`@autosave`。

编辑器预览必须能从标题场景进入共通篇，并从地下通道的三个选择分别进入三条路线。重载预览时旧背景、立绘、BGM 和 SE 不得残留；缺失资源继续使用现有占位回退并记录可诊断警告。

标题页使用渲染器字体排版“零点之后 / AFTER MIDNIGHT”，采用冷白字标、细分隔线和少量金色 `00:17` 标记，不将 Logo 烘焙进背景图，以保证窗口缩放和未来换字体时可维护。

## Testing And Acceptance

自动验证：

- `npm run typecheck`
- `npm run test`
- `npm run lint -w zero-after-midnight`
- `npm run simulate -w zero-after-midnight`
- `npm run build -w zero-after-midnight`
- `npm run lint -w surdet-starter`
- `npm run simulate -w surdet-starter`
- `npm run build`
- `git diff --check`

新增或补充验证：

- 三个路线选择均能从共通篇到达正确场景和结局。
- `trust`、`evidence`、`panic` 的高低组合都能稳定完成，不出现未初始化变量或死链。
- 所有背景、立绘、头像、BGM、SE 引用都有资源或明确占位回退。
- 预览重载后不残留旧背景、立绘、音频和 Blob URL。
- 自动存档、手动存档、读档、跳过、自动播放、隐藏界面、右键和手柄输入不改变已有行为。
- `1280×720`、窄窗口和移动尺寸下标题、对白、选择肢和操作带不溢出。
- 单路线实际阅读与演出时间落在 55～70 分钟区间。

## Scope And Defaults

- 不做全语音；仅保留氛围 BGM 和环境/交互 SE。
- 不引入战斗、日历、小游戏、实时电话 UI 或新的解释器语法。
- 参考作品只影响构图、留白、字标和交互克制感，不复制角色、背景、Logo 或素材。
- starter 继续作为引擎验收样例；完整游戏独立放置，避免示例回归风险。
- 先完成共通篇、路线骨架和资源契约，再生成高分辨率素材；素材生成失败时优先保留剧情与演出结构，使用占位回退，避免阻塞脚本验证。
