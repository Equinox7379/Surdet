# Surdet 素材中心目录导航设计

## 目标

让大型项目能够按现有素材文件夹快速收窄素材列表，同时保留搜索、分类、状态、排序、预览、引用定位和导入链路的既有行为。

## 产品边界

- 只读取 `ProjectAssetItem.sourcePath`，不扫描磁盘、不建立第二套素材索引。
- 只修改 Editor；不改变 Authoring、CLI、Agent Port、导入 authority、项目文件和素材引用。
- 目录导航只负责筛选，不提供新建、改名、移动、删除或覆盖。
- 缺失引用没有物理目录，继续由“引用缺失”状态呈现，不伪造目录位置。
- 本增量不承担整体前端视觉重构；继续使用当前 token，避免新增卡片墙、彩色选中竖线或悬浮操作条。

## 交互设计

素材库标题区增加“位置”选择器。默认值为“全部位置”；目录选项来自现有物理素材路径，父目录排在子目录之前，并显示包含后代目录在内的素材数量。

选择目录后：

1. 素材列表只显示该目录及其子目录中的文件；
2. 搜索、分类、状态和排序继续叠加生效；
3. 标题下方显示 `全部位置 / …` 面包屑，可逐级返回；
4. 大文件或问题导航直接定位某项素材时自动清除目录限制，避免目标被隐藏；
5. 项目切换或刷新后，若原目录已不存在，状态自动恢复为“全部位置”。

窄屏时，位置与排序控件改为纵向排列，面包屑允许横向滚动，不引入桌面文件树。

## 数据与安全规则

目录身份使用规范化的项目相对路径，分隔符统一为 `/`。只有 `content/assets` 本身及其安全后代目录可进入选项；绝对路径、盘符、空段、`.`、`..` 和前缀相似但不在目录边界内的路径均忽略。

目录匹配必须按路径段边界判断。例如选择 `content/assets/bg` 时可以包含 `content/assets/bg/night/file.png`，但不能包含 `content/assets/bg2/file.png`。

## 代码边界

- 新建 `packages/editor/src/panels/asset-center-folders.ts`：纯目录规范化、选项生成、面包屑和目录匹配。
- 修改 `packages/editor/src/panels/asset-center.ts`：把目录作为现有筛选轴，并渲染位置选择器与面包屑。
- 修改 `packages/editor/src/state.ts`：增加当前目录状态。
- 修改 `packages/editor/src/styles/asset-center.css`：为位置控件和面包屑提供宽屏/窄屏布局。
- 新增聚焦目录测试，并扩展现有素材中心合同测试。

## 完成标准

- 目录选项稳定、去重、父级先于子级，数量包含后代。
- 目录与搜索、分类、状态、排序组合正确。
- 路径边界、非法路径和无物理文件均 fail closed。
- 鼠标与键盘改变目录后焦点可恢复。
- 宽屏和 800px 视口无横向页面溢出，关键操作仍可见。
- Editor 聚焦测试、typecheck、build 和一次实际浏览器检查通过。
