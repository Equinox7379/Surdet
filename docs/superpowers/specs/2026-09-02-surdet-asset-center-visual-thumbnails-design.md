# Surdet 素材中心可视缩略图设计

## 目标

把素材中心现有的“文字网格”升级为真正可浏览的视觉素材库。用户切换到网格视图后，应先通过画面辨认背景、立绘与头像，再阅读名称、路径和引用信息；列表视图继续承担高密度检查，不被改造成大卡片墙。

本增量借鉴成熟创作工具“用真实素材承担视觉识别”的工作方式，但不复制任何第三方品牌、配色、图标、代码或资产。

## 产品边界

- 只修改 Editor，继续以 `ProjectAssetItem` 和现有 `DirAsset.handle` 为事实来源。
- 不修改 Authoring、CLI、Agent Port、导入 authority、项目格式或素材引用。
- 不创建缩略图数据库、生成清单、磁盘缓存、第二套素材索引或后台扫描服务。
- 不新增创建、改名、移动、删除、覆盖、转码、优化或自动修复。
- 第一版只为可由浏览器直接读取的图片生成真实缩略图。音频、视频、字体、其他文件和缺失引用使用克制的中文类型占位；不得伪造画面。

## 交互与视觉设计

### 列表视图

列表继续显示名称、类别、格式、项目路径、大小和引用数量。缩略图容器在列表中不占空间，不触发二进制文件读取。

### 网格视图

每个素材条目顶部增加稳定的 16:9 预览区域：

- 背景使用 `cover`，便于快速扫描场景；
- 立绘使用 `contain`，避免裁掉人物主体；
- 头像使用 `cover`，保持紧凑识别；
- 图片读取中显示“正在读取”；
- 本地句柄不可用时显示“暂无缩略图”；
- 缺失引用显示“文件缺失”；
- 音频、视频、字体和其他文件显示类别与格式，不制造假缩略图。

界面本身保持中性，让真实素材成为网格中唯一显著的色彩来源。不得增加彩色左/上竖线、渐变、玻璃拟态、状态胶囊墙或无意义装饰。

缩略图是条目名称的视觉补充，使用空 `alt` 并设为装饰性；完整可访问名称仍由真实按钮文字提供。选择、键盘焦点和状态信息继续依靠现有按钮语义。

## 加载与资源生命周期

大型项目可能包含数百张图片。进入网格时若立即读取全部文件，会产生无必要的文件 I/O、Object URL 和解码内存。因此允许一个小型、仅存在于当前素材中心页面生命周期内的可见区域加载器：

1. 使用 `IntersectionObserver` 在条目接近视口时读取图片；`rootMargin` 只做少量提前加载。
2. 浏览器不支持观察器时退化为即时加载，功能仍可用。
3. 每个缩略图只读取对应现有文件句柄，不枚举新目录、不更改共享素材事实。
4. 图片加载完成或失败后立即撤销临时 Object URL。
5. 重新筛选、切换视图、切换项目、离开素材中心或页面卸载时断开观察器，并撤销仍在等待的 URL。
6. 异步结果必须受当前页面 generation 约束；旧页面完成的读取不得写回新页面。

这项工程化的理由仅限于控制真实的大型项目 I/O 和资源生命周期。它不是缓存框架，不保留跨页面状态，也不引入通用任务调度层。

## 代码边界

- 新建 `packages/editor/src/panels/asset-center-thumbnails.ts`：缩略图描述、可见区域观察、异步读取和 Object URL 释放。
- 修改 `packages/editor/src/panels/asset-center.ts`：在网格条目中挂载预览区域，并与现有渲染生命周期共同释放资源。
- 修改 `packages/editor/src/main.ts`：离开素材中心时同时释放详情预览和网格缩略图。
- 修改 `packages/editor/src/styles/asset-center.css`：加入克制的缩略图舞台和网格层级；列表保持原有密度。
- 新增聚焦缩略图描述测试，并扩展素材中心合同测试。

## 失败行为

- 文件句柄缺失、读取失败或图片解码失败时，条目仍完整显示并可选择。
- 失败仅影响当前缩略图，不清空素材列表、不修改素材状态、不污染详情预览。
- 异步失败不产生全局错误提示；缩略图区域用中文说明当前状态。
- 旧 render 的异步结果必须静默失效，不得替换新筛选结果的 DOM。

## 验证范围

- 永久测试覆盖缩略图描述、图片适配方式、非图片/缺失占位和生命周期合同。
- 素材中心聚焦测试、Editor typecheck、Editor build 各运行一次。
- 实际浏览器在 1440px 与 800px 检查：网格真实图片、列表不加载缩略图、筛选后无旧图串位、切换视图释放资源、页面无横向溢出。
- 若聚焦修改后 Editor 全量测试通过一次，不因形式重复运行。

## 仓库卫生

本轮只删除能够证明已无生产、测试、脚本或文档职责的文件。只读审查已确认现有素材中心 runner、runner contract、侧栏适配器和共享素材模块仍有直接调用或回归价值，因此不把它们作为删除候选。任务生成的临时浏览器脚本只放 D 盘，完成后删除，不进入仓库。

## 完成标准

- 网格中的真实图片可视辨认，列表视图保持紧凑。
- 图片只在接近视口时读取；非图片不会触发图片文件加载。
- Object URL 和观察器在成功、失败、重绘与离开页面时均正确收束。
- 缩略图失败不影响条目、筛选、选择、详情预览或引用导航。
- 1440px 与 800px 无横向溢出，键盘选择和焦点行为不退化。
- 未增加第二套索引、后端写入或素材变更能力。
