# 预览会话与素材生命周期修复

## 目标

让编辑器预览与 starter 运行时在会话重载、图片字体加载和基础输入状态上保持一致，为后续 ADV 视觉升级提供可靠的真实素材管线。

## 实施范围

1. 为 `AdvRenderer` 与 `PixiStage` 增加会话重置边界，清理文本、选择肢、NVL、Backlog、立绘、背景和覆盖层状态。
2. 让编辑器预览读取项目目录中的背景/立绘图片字节并传入 iframe，预览等待资源注册完成后再启动解释器；修复字体缓存和无字体回退。
3. 让 starter 等待图片注册完成，并阻止标题画面继续接收游戏输入；回到标题/新游戏时清理旧游戏画面。
4. 修复 Backlog 点击关闭后内部状态未同步的问题，并补充生命周期回归测试。

## 验证

完成后运行全局 typecheck、test、starter lint/simulate 和 build；不在本批次扩展大规模视觉样式重制。
