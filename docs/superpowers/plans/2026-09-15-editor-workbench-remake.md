## 失败记录及处理边界

- 原全应用脚本直接填入已折叠的旧查找框，首次超时；改为通过原 `Ctrl+F` 展开再操作。时间轴节点断言曾误写“屏幕”，已改为共享真实名称“画面效果”。
- 长项目名在窄窗口溢出，已给项目上下文子项完整宽度约束。其间两次针对构建产物的复验未重新构建，仍命中旧 CSS；新鲜构建后通过，不把旧产物结果当成修复失效或成功。
- 保存回归初次遇到 `HUMAN_WORKSPACE_STATE_CORRUPT`，定向诊断确认是测试关闭前一浏览器上下文时异步撤销请求可能被中止，旧会话进入服务规定的 grace 保护，并非新 UI 修改了保存合同。测试现在等待真实 HTTP snapshot 确认仅剩一个活动会话、无 grace 会话，再验证单 Editor 保存；没有删除状态、假报 clean、自动重试实际写入或改服务门限。临时服务端诊断已移除。
- 后续连续切换曾实际捕获三条已销毁 Renderer 的轨迹查询错误，前述关闭失效修复及确定性反例覆盖此因；修复后真实磁盘回归无浏览器错误。
