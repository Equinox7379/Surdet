## 产品目标与不可丢失的决策

Surdet 首先服务 Owner 的真实创作和游玩体验。目标是让人类与外部电脑 Agent 使用同一套引擎，可靠地产生可试玩、可修订、可接管的普通 Galgame 项目。

1. **外部 Agent 负责智能，Surdet 提供能力。** 不内置模型、聊天产品或通用 Agent 调度平台；不绑定模型供应商，不把普通创作和游戏运行变成必须联网的服务。
2. **双向因果创作台。** 编辑对象、正式运行预览、状态变化及影响定位应连成短闭环；人类能从画面回到源对象，也能从对象进入真实运行。不复制简化预览状态机。
3. **单一共享创作内核。** `@surdet/authoring` 承担对象、类型化修改、隔离变更和证据语义；CLI/MCP/Editor 是适配层。Core 保持纯运行语义，Renderer/Host/Shell 各守公共边界，不另造 Player、保存或回退真相。
4. **普通、开放的项目。** 保留可直接理解和继续编辑的内容文件，不引入 Agent 专属项目格式。命名对象使用语义身份；匿名对象用当前修订的精确引用和指纹，不猜引用、不模糊重定位、不逐行塞永久 UUID。
5. **先隔离，明确授权后写回。** 普通草稿、候选、组合结果和批准回执有各自身份；未知提交结果先核对原操作，不通过新编号或放松检查来掩盖失败。人类草稿、来源文件、未知外部改动及恢复材料必须保全。
6. **工程可靠不等于作品完成。** 运行和测试不能替代剧本、美术、声音、阅读节奏和玩家手感判断。已有演示和短篇的技术通过不能被用来反驳 Owner 的质量反馈。
7. **按真实需求演进。** 保留有效工作基线，优先复用已有模块，不预建扩展市场、多后端、迁移平台或通用框架；不为理论零风险堆叠审计、哈希、审批和报告。

## 已完成阶段：默认完整创作路径

该阶段及单作者试验已通过复核并结束。具体任务、依赖、合同与验收只维护在[本阶段实施计划](2026-09-23-default-authoring-path.md)，不重复扩写台账，也不重新开始全仓审计。

1. **公开入口自洽。** 让创作示例可执行、内容作者能发现实际可用能力、读取来源明确、对象修改后可继续定位、错误提示提供真实可执行的恢复办法。复用既有注册表、文档、错误目录和测试。
2. **普通创作不必强制组合。** 已支持显式 direct/candidate，省略参数保留 stage→candidate、apply→direct 的默认值；模式与来源写权限分开，不删除候选依赖环检查，不擅自给予 apply 权限。
3. **普通项目可交付。** 内容作者应能利用共享 Player 完成项目入口、目标路线、试玩与必要说明；交付后人类可以继续编辑，不要求内容 Agent 重写播放器。

成功标准是只靠正式入口完成有分支、有演出、经过返修的可运行项目，不依赖开发者解释隐藏字段、手工补文件或绕过保护。本轮单作者试验已按新增授权完成；它的人工反馈和样本限制见实施计划。再次试验仍按当轮授权执行，不每修一个函数就重跑历史 Q1。
