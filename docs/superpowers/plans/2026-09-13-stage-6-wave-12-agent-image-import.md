## 实施与不变量

1. 打通来源发现 → 暂存 → 明确提交 → 素材目录 → 原有剧情编排这一条真实纵向路径。
2. 暂存只写独立数据区；正式导入遵守 apply policy、项目租约、其他素材事务恢复屏障和现有草稿保护。不覆盖同名资源。
3. 来源目录在启动时授权并核对实际物理路径；请求不能扩权为任意读盘或下载。MCP 仅投影共享能力，不以 roots 充当权限检查。
4. 同一 operationId 持久绑定导入请求；中断或响应丢失后先查询并续接同一操作。状态不明不另建；封存请求不能换图或换目标。
5. 素材导入后重新读取项目和资源事实，再开始引用它们的剧情 change；不更新旧候选、不承诺图片与剧情的跨事务原子提交。
