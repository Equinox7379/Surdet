## 目标和执行顺序

一个联合目标：外部 Agent 创作、调整章节的剧情结构和现有非音频演出，在未写回来源项目的版本里真实试玩、读取对应观察、定点返修，最后经已有授权及回执流程交付可由人继续编辑的普通项目。

1. 主代理先贯通当前工作变更的预览与正式观察、返回对应变更返修的最小纵向路径；不先写回，不替用户保存或丢弃草稿。然后补齐封存候选和组合结果的同源打开、失效检查和返修出口。
2. 剧情结构：完整选择组修改，配对且支持嵌套的条件块及分支编辑，保留未选正文/注释；复用 Core 解析并补必要源码边界。新结构操作按当前完整引用与原内容指纹拒绝过期目标，失败无持久变更。增加受控变量初值修改；相关 set/mod/goto/jump 与非音频演出指令沿用原位替换。
3. 时间轴：沿用 Core 的 background/portrait/camera/screen/particle 动作、参数与约束，补时间轴总时长、轨道目标和节点修改。公开发现、差异、依赖、封装和重放同步接通；处理实际运行端的相关契约缺口，包括待复现的 particle stop 字段要求差异。
4. 返修后恢复测试位置：使用原解释器重新运行、绑定入口/选择身份/随机种子和目标位置；选择或条件不再匹配时停在需重新选择的位置，不按旧数字猜选项或注入猜测状态。编译失败不把旧画面宣称为新版本。
5. 一个隔离多场景三结局章节完成公开能力创作、条件选择/状态/CG/镜头/转场、未写回版本三类返修、候选组合与明确写回、实际玩家结局与相关存读档/演出恢复验证。主代理核对真实画面和最终差异，复用仍有效的旧结果。

## 必须保持的边界

- 工作变更可继续编辑；封存候选和正式组合结果只读，返修回到可编辑变更并重新封装或组合，不篡改旧封存内容、不沿用失效批准。普通预览与观察不批准、不写来源，不借 Wave 11 回源导航绕开隔离返修。
- 新能力进入同一 shared authoring 合同、原事务、校验、对象事实、候选和重放；同场景/同对象竞争仍明确冲突，不承诺任意指令自动合并。
- 各预览绑定项目、来源种类、工作版本或封存身份、预览代次及实际资源事实；切换和改动后旧观察失效。正常项目 content/assets 与 public 素材布局继续支持。
- 不改正式《零点之后》，不包含音频、配音、视频、新素材生产、变量改名/类型迁移、旧玩家存档迁移、云同步、发行、整体 Editor 重做或下一批功能。
