# CLI 许可范围

Surdet CLI 自有技术代码按同目录 `LICENSE` 中的 MIT 许可证提供。`templates/game/content/` 中的作品剧情、图片和其他创作素材不自动适用引擎的 MIT 许可；其对外公开与再分发范围目前尚待 Owner 明确。

The MIT license covers Surdet CLI code, not an automatic license to its bundled game artwork or story content. Check the separate asset permissions before redistributing a template or a generated game. The engine does not require your own game to be open source.

依赖保留各自原许可。当前仅做开源准备，尚未公开发布此 npm 包。
