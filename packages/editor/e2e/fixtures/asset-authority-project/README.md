# Asset-authority test data

Small SVG, scene, timeline and configuration inputs frozen from the former Starter at `cec7dc4806b7998dc5618e666b701ec553c8271a`.

These files intentionally contain the same background/portrait references used by the asset import, relocation and undo browser contracts. They are test data, not another runnable game or player implementation. No runtime, font, save or user data is included. Keeping the fixture here lets the real Starter evolve without silently changing the behavior those tests exercise.
