# 《雾港来信》素材

本作包含三幅背景、凛的三种表情立绘和一个同源头像。背景与立绘通过 Codex 内置 `image_gen` 生成；立绘按 Owner 指定的《零点之后》女主画法重做，以简洁二维线稿、灰蓝色块和克制明暗表现。Owner 明确允许本地抠图后，去掉生成器画入的背景，保留人物 RGB 像素并写入真实 PNG alpha；头像从常态立绘截取。

| 文件 | 用途 |
| --- | --- |
| [bg/harbor.png](bg/harbor.png) | 标题与港口开场 |
| [bg/post_office.png](bg/post_office.png) | 旧邮局档案室 |
| [bg/lighthouse_dawn.png](bg/lighthouse_dawn.png) | 灯塔与结局 |
| [portrait/lynn_coat_normal.png](portrait/lynn_coat_normal.png) | 凛的主立绘 |
| [portrait/lynn_coat_hesitant.png](portrait/lynn_coat_hesitant.png) | 犹豫与旧事相关对白 |
| [portrait/lynn_coat_smile.png](portrait/lynn_coat_smile.png) | 澄清误会后的释然 |
| [avatar/lynn.png](avatar/lynn.png) | 对白头像，由主立绘派生 |

图像提示词与透明底处理记录见 [PROMPTS.md](PROMPTS.md)。人物是虚构的成年邮差；三个表情保持同一服装、姿势和画布尺寸。风格参考为本仓库《零点之后》的女主立绘，正式游戏原图保持只读。三幅背景共享海雾、石砌码头、旧邮局与灯塔的场景语言。

正文和界面使用仓库既有、未修改的 MiSans 字体；标题沿用 Renderer 的宋体/思源宋体回退。软件标题页已注明 MiSans。字体说明与官方许可链接见 [fonts/NOTICE.md](fonts/NOTICE.md)。

当前没有音频素材，剧本也没有虚假的音频引用，鉴赏的音乐页保留真实空状态。引擎的音频能力与设置继续可用，作者添加真实文件后再引用。
