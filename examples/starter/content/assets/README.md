本作原图像提示词及历史素材记录见 [PROMPTS.md](PROMPTS.md)。人物是虚构的成年邮差；三种表情保持同一服装、姿势和 1024×1536 画布。当前立绘使用生成器输出的真实 PNG alpha；本次未在本地重绘或抠图。旧背景已从活动路径替换，可由Git历史恢复；不再作为运行时备用图。头像仍沿用原素材。

正文和界面使用仓库已有的 Noto Serif SC（思源宋体系列）可变字体，复制自《零点之后》，未修改字体。许可见 [fonts/OFL-NotoSerifSC.txt](fonts/OFL-NotoSerifSC.txt)。旧 MiSans 文件及 [fonts/NOTICE.md](fonts/NOTICE.md) 仍保留；标题字标是图像，不依赖客户端安装字体。

当前没有音频素材，剧本也没有虚假的音频引用，鉴赏的音乐页保留真实空状态。引擎的音频能力与设置继续可用，作者添加真实文件后再引用。
