# 零点之后

原创都市悬疑现代 ADV。地下通道的选择进入证词、赴约或静音路线。

`npm run dev` 启动预览；`npm run lint` 校验剧本；`npm run simulate` 遍历分支；`npm test` 校验三结局和素材；`npm run build` 生成发布包。

`examples/starter` 保持为引擎验收样例，本目录是独立完整游戏。
