# 《雾中回响》— 游戏设计与通关指南

> 引擎：Surdet · 类型：都市奇幻悬疑恋爱 ADV · 版本 0.1.0
> 入口场景：`prologue`（已在 `src/main.ts` 配置）

---

## 一、剧情概要

滨海城市雾港市，每十年迎来一次「大雾纪」。雾中会浮现逝者记忆的残响——**回声**。
十年前的白鹭街区一夜消失，官方称为"大气异常"。主角 **陆屿** 在那场雾灾中失去了妹妹 **陆安安**，从此成为全城唯一听不见回声的"雾盲人"——因为他从未停止记住她。

大雾纪第四十天，雾开始下沉、回声实体化。全城封城之际，三条线索同时指向"雾眼"：
雾的源头，也是这座城市十年未愈的伤口。陆屿必须选择一条路走下去，而这场雾，不会等任何人。

主题：**告别与被记住**。雾 = 被遗忘的记忆；只有听完那句没说完的话，雾才会散。

## 三、路线与结局（共 5 个）

```
序章 prologue ──→ 第一章 ch01 ──→ 第二章 ch02 ──→ 第三章 ch03
                                                        │
        ┌───────────────────────────────┬──────────────┴───────────────┐
        ▼                               ▼                              ▼
 route_lin_01→02                 route_su_01→02                route_xiaoman_01→02
        │                               │                              │
   ├── 好感到位 ──→ 真结局      ├── 好感到位 ──→ 真结局       ├── 好感到位 ──→ 真结局
   └── 否则 ──→ 「霜落」       └── 否则 ──→ 「雾散」        └── 否则 ──→ 「满月」

 ch03 选择「独自冲进雾里」─────────────→ BE「迷雾孤岛」
```

进线条件（第三章选择肢的显示门槛）：对应角色好感度 **≥ 8**；三条线好感均不足时只能进 BE。

### 结局达成条件

| 结局 | 场景 | 达成条件 |
|---|---|---|
| BE「迷雾孤岛」 | bad_end | 第三章选「独自冲进雾里」（无门槛） |
| NE「霜落」 | route_lin_end | 走林霜线，且不满足真结局条件 |
| NE「雾散」 | route_su_end | 走苏晚晴线，且不满足真结局条件 |
| GE「满月」 | route_xiaoman_end | 走小满线，且不满足真结局条件 |
| **TE「雾尽天明」** | true_end | 走任意一条线，且 **lin.trust ≥ 4 且 su.trust ≥ 4 且 xiaoman.trust ≥ 5** |

### 真结局攻略提示（单周目可达）

前两章把三人的羁绊都养够，再进任意一条线，结局前自动进入 TE：

- **林霜**：序章"承认听见了"(+3) + 追出门(+1) → 4 达标
- **苏晚晴**：第一章"配合她站进雾里"(+4) → 4 达标
- **小满**：第一章"答应常去满月堂"(+3) + 送咖啡固定(+2) → 5 达标
- 注意：小满和红裙子线（章内选择）与好感无关，可任意选。

## 四、变量清单

声明于 `game.config.json`（lint 强制：所有变量先声明后使用）：

| 变量 | 类型 | 初始值 | 说明 |
|---|---|---|---|
| `heroName` | string | "陆屿" | 主角名，正文以 `{heroName}` 插值 |
| `lin.trust` | number | 0（min 0 / max 100） | 林霜好感度 |
| `su.trust` | number | 0（min 0 / max 100） | 苏晚晴好感度 |
| `xiaoman.trust` | number | 0（min 0 / max 100） | 小满好感度 |
| `heard_echo` | flag | false | 序章是否追入雾中（影响第二章开场文本） |
| `heroine` | string | "" | 当前路线标记："lin" / "su" / "xiaoman"，真结局开场差分用 |

## 五、操作方式

- 点击画面推进文本
- **F5** 快速存档 · **F9** 快速读档
- **A** 自动播放 · **S** 快进（跳全部，直到选择肢）
- 通关后解锁 CG 回想（`@unlock_cg`，各结局 1 张）
